# Mainsail-OIWP
It's called the future.

Mainsail OIWP is a modified version of [Mainsail](https://github.com/Mainsail-crew/mainsail) as an intent of making DIY mainline Klipper printers beginner friendly. It is familar yet different. It is a part of [OitswilliamV2](https://github.com/Bunny350/OitswilliamV2) project.

## This is a proof of concept, but it might work.
**There are glitches such as panels not positioning correctly in mobile layout, and certain features, like accessibility options, are not implemented.**

This version currently is an experimental proof of concept. But it might get out of this phase within a short period of time.

### Cheatsheets
All contributions of this is relied on the original documentation. You can [visit here](https://docs.mainsail.xyz/development/contributing/).

Do not ask me to request pull this to the original repository.

## Goals
* Migrate to Vue 3 and Vuetify 3 and then 4, because Vue 2 is ended-of-life,
* Make probe offsetting beginner-friendly,
* Any more, if I have thought about them.
